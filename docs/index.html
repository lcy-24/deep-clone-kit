结论

JSON 方案：循环引用直接抛异常；Date 变字符串、Map/Set/RegExp 变空对象、undefined/函数/Symbol 丢失。
deepClone：全部正确重建，循环引用关系保留（copy.self === copy），13 项边界自测全通过。
